🍞 **Warm Loaf Bakery & Cafe — Frontend UI**
Where every loaf is a "purr-fect" slice of heaven.

Welcome to the frontend repository for Warm Loaf Bakery & Cafe! Inspired by the comforting aroma of freshly baked artisanal bread and the cozy posture of a sleeping cat, this project provides a warm, inviting, and seamless digital experience for web visitors.

**🌟 Key Features**
• **Warm & Cozy Aesthetic**: Custom brown and cream earth-tone design system, tailored typography, and playful cat-themed branding details.
• **Hero Landing Header**: Features an interactive navigation bar, brand logo, tagline, and an active shopping cart counter badge.
• **Storytelling "About Us" Section**: A visually balanced split layout showcasing the bakery's origins, artisanal philosophy, and cozy interior atmosphere.
• **User Authentication Interfaces**: Built-in UI entry points for Sign Up and Login user flows.
• Responsive Layout: Structured with semantic HTML5 and CSS for clean presentation across desktop and mobile browsers.

**🛠️ Tech Stack**
• **HTML5**: Semantic document structuring (<header>, <nav>, <section>, <footer>).
• **CSS3**: Custom styling, color palettes, typography, and layout positioning.

**🚀 Getting Started**
1. Clone the repository: git clone https://github.com/arckhyved/warm-loaf-cafe-frntnd.git
2. Navigate to the project directory: cd warm-loaf-cafe-frntnd
3. Open in browser: Simply open index.html in your web browser or launch it using VS Code Live Server / Notepad++ preview.
