# 🍞 Warm Loaf Bakery & Cafe — Frontend UI

> *Where every loaf is a "purr-fect" slice of heaven.*

Welcome to the frontend repository for **Warm Loaf Bakery & Cafe**! Inspired by the comforting aroma of freshly baked artisanal bread and the quiet, cozy posture of a sleeping cat, this web interface provides an inviting, warm, and seamless digital experience for visitors.

---

## ☕ Overview

**Warm Loaf Bakery & Cafe** is a front-end web application built to showcase the bakery's brand identity, artisanal menu offerings, and physical cafe atmosphere. The interface focuses on clear visual hierarchy, accessible navigation, and engaging cat-themed branding elements.

---

## 🌟 Key Features

* **Hero Landing Page:** Features a custom brand logo, primary navigation links (Home, Sign Up, Login), and an active shopping cart badge counter.
* **Storytelling "About Us" Section:** A balanced two-column layout highlighting the cafe's founding story, baking philosophy, and warm community atmosphere alongside interior cafe photography.
* **User Authentication UI:** Dedicated user interface components for guest registration (**Sign Up**) and existing user session access (**Login**).
* **Interactive Elements:** Cart counter notification badge and navigation hover interactions for an intuitive user journey.

---

## 🎨 Design & Aesthetic

- **Color Palette:** Warm earth tones including deep caramel brown (`#8B4513`), soft cream background (`#FFFDD0`), and dark coffee accents.
- **Typography:** Friendly, rounded headline fonts paired with clean, readable body typography.
- **Theme:** Cozy cat cafe aesthetic combining artisanal bakery motifs with playful feline illustrations.

---

## 🛠️ Tech Stack

- **HTML5:** Semantic document markup (`<header>`, `<nav>`, `<section>`, `<article>`, `<footer>`)
- **CSS3:** Custom styling, layout positioning, flexbox structures, and web font integration

---

## 🚀 Installation & Local Setup

1. Clone the repository: `git clone [https://github.com/arckhyved/warm-loaf-cafe-frntnd.git](https://github.com/arckhyved/warm-loaf-cafe-frntnd.git)`
2. Navigate to the project directory: `cd warm-loaf-cafe-frntnd`
3. Run the project: Simply double-click `index.html` to open it in your browser, or launch it using a local development tool (such as VS Code Live Server or Notepad++ HTML Preview).
